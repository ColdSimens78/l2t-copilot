# AGENTS.md — инструкции для AI-агентов в этом репозитории

L2T Copilot разрабатывается **мультиагентной командой**: сессии-агенты
(Кодер, Фронтендер, Разведчик, Исследователь) работают под координацией
«Папы» (архитектор/менеджер), владельцем является человек (Ilmir).
Этот файл — контракт для любого AI-агента, который вносит вклад в код.

## 1. Прочитай прежде, чем писать

1. [`README.md`](README.md) — § «Контракт шины» (7 правил, выжаты из реальных
   инцидентов) и § «Ключевые механизмы».
2. [`docs/ipc-contract.md`](docs/ipc-contract.md) — единый источник типов
   фронт↔ядро. **Схема версионируется**; расхождение сторон = баг.
3. [`DECISION.md`](DECISION.md) — принятые архитектурные развороты (не
   переоткрывай решённое).
4. [`docs/prd-l2t-v0.2.md`](docs/prd-l2t-v0.2.md) — ценности и метрика
   Acceptance Rate.

## 2. Правила коммитов (правило №6 — выучено кровью)

- **Запрещён `git add -A` / `git add .`** — только явные пути твоих файлов.
  Инцидент: чужой недописанный документ улетел в публичный коммит.
- Cross-cutting коммиты (несколько областей) — только «Папа».
- Conventional Commits + scoped-объём: один смысл = один коммит, тесты рядом.
- Push в `main` — только с зелёным CI (`ci.yml`: pytest + cargo test).

## 3. Контракт шины — 7 правил (кратко)

1. Workspace — граница песочницы (`import_*` только из workspace, рендеры туда же).
2. `timeoutMs` на каждый вызов; **таймаут ≠ отказ**: после таймаута — inspect
   состояния, потом решение.
3. Ошибка = JSON-RPC error **с текстом** (на mcp SDK 2.x текст доносит только
   `ToolError` — см. `_bounded` в `midi_gen/server.py`); никаких зависаний.
4. Сессия — источник истины: генераторы не вшивают `set_tempo`
   (`embed_tempo=False` по умолчанию).
5. Lifecycle хоста: wake-паттерн (поднять → подождать → retry), попытки видны.
6. Дублирование клипов экспоненциально: N копий = `ceil(log2 N)` вызовов.
7. Self-Check: relative-key equivalence (`core.keys.keys_match`) + перепроверка
   тональности ПОСЛЕ завершения аранжировки.

## 4. Твои права и границы

- **Можешь сам**: технические решения внутри своей задачи; выбор
  библиотек с лицензией MIT/Apache/BSD/ISC (проверяй LICENSE-файл, не бейдж);
  стиль там, где спека молчит.
- **Через предложение** (issue или секция предложений): изменения
  IPC-контракта, новые зависимости, архитектура.
- **Нельзя**: чужие файлы, `git push` без явной авторизации в задаче,
  GPL/AGPL-код в репо, скрытые от лога действия.

## 6. Стиль кода

- Rust: serde-типы контракта в `contract.rs`, фасады в facade, bounded-ошибки
  (`CoreError`) с текстами для AI Dock.
- Python: логика без транспорта (`logic.py`), MCP-обертка отдельно
  (`server.py`), dual-шим SDK 1.x/2.x, MockTransport в тестах (живые серверы
  в тестах не дёргаются).
- Детерминизм генерации: никакого randomness — контракт проверяется
  байт-в-байт.
