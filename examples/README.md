# Примеры: тестовые лупы

Сюда кладутся лупы для проверки пайплайна «анализ → генерация → DAW».

Правила:

- только материалы без лицензионных ограничений (свои записи, CC0-сэмплы);
  **приватные записи в репозиторий не попадают**;
- нейминг: `<источник>_<bpm>_<key>.wav`, например `loop_cc0_120_C-major.wav`;
- `.gitignore` маскирует аудио-рендеры (`*.wav`, `*.flac`, ...) и сессии
  (`*.scraftz`) по всему репо, но **разрешает** `examples/**/*.mid` —
  маленькие MIDI-лупы коммитить можно;
- пока каталог пуст: положите любой луп на 1–4 такта и повторите сценарий
  из README («Пример сценария»).

Восстановить наш тестовый сценарий без приватных данных: любой моно луп
~4 c, 44.1 kHz — анализ даст BPM/тональность, дальше сгенерируйте партии
в этой тональности и сравните результат через `compare`.
