**Автор:** Фронтендер (дочерняя сессия) · **Дата:** 2026-11-22
**Задача:** чек-лист §10.2 proposal v0.3 — шрифты, HTML-audio (gapless-луп), drag-and-drop из файлового менеджера, always-on-top, потребление памяти. Выход: go/no-go по WebKitGTK + вводная для решения по превью-рендеру (§11 в.3).

## 2. Выводы

**Go.** WebKitGTK 2.54 на Debian 13/KWin X11 работоспособен для кокпита: сборка, окно, webfonts, IPC, стабильность процесса — чисто; в логе нет ни одного предупреждения GTK/WebKit. Fallback «локальный web-UI» (VISION v2) **не активируем** — он остаётся задокументированным планом Б.

Найденное (не блокеры, в трекер):

1. **Автоплей HTML-audio блокирован** (AbortError без жеста) — ожидаемое поведение WebKit; в продукте превью всегда стартует кнопкой. Для A/B-аудиции слоёв (§4.2) это ничего не ломает.
2. **Always-on-top не отражается в состоянии** после успешного `setAlwaysOnTop(true)` — кандидат в upstream issue (tao/KWin X11). Проверка человеком: кнопка «включить/выключить» на spike-странице — окно должно встать поверх.
3. **Gapless-шов лупа не измеряется автоматически** — слуховая проверка владельцем (тыкнуть ▶ на spike-странице: стык 3-секундного тона должен быть бесшовным). Если шов слышен — для превью уходит в Web Audio `loop` точки либо в сайдкар-рендер длинного WAV.
4. Настройка `identifier` заменена `com.tauri.dev` → `io.github.coldsimens78.l2t-cockpit` (честный bundle id).

## 3. Решение по превью-рендеру (§11 в.3, вводная)

Спайк подтверждает: **сайдкар GM-синт первым** (решение Папы из собрания) полностью совместимо с платформой — `<audio>` в WebKitGTK играет WAV-файлы, автоплей-ограничение совпадает с UX продукта (старт по кнопке). Следующий шаг этапа 1 — Tauri-обёртка кокпита (окно грузит React-приложение вместо spike-страницы; `tauri.conf.json` уже указывает `devUrl` на vite :5199 и `frontendDist ../dist`).

## 4. Как воспроизвести

```bash
cd ui && pnpm install && (pnpm dev --port 5199 &)   # vite
cd ui/src-tauri && cargo build && DISPLAY=:0 ./target/debug/app
# лог: SPIKE-строки; страница: шрифты, ▶ луп (жест!), AOT-кнопка, дроп-зона
```

Чек-лист проверки человеком (5 минут): ▶ луп — послушать стык; дроп файла из Dolphin — увидеть `tauri://drag-drop` в логе; кнопка AOT — проверить поверх-поведение.
