# DawBackend — контракт адаптеров DAW (Wave 2)

Философия экосистемы: **наша ценность — AI-слой, DAW — сменное «тело»**.
Один контракт — много хостов. Образец словаря:dawmcp (vecnode/dawmcp) и его
DAW-агностичные бэкенды; иронично и удобно, что именно он доказал подход.

## Принципы (наследуют «Контракт шины», README §7)

1. **Workspace — граница песочницы**: `import_midi` читает только из
   workspace; `render` пишет только туда.
2. **Сессия — источник истины** для темпа/тональности: генераторы не вшивают
   `set_tempo`; хост применяет `adopt_loop` только по явной команде агента.
3. **Компактный JSON + bounded-ошибки**: любой некорректный параметр —
   мгновенная ошибка, никаких зависаний; паника хоста не должна оставлять
   клиента висеть (таймаут на каждый вызов).
4. **Pull-семантика**: агент делает `get_session` перед действием; undo
   хоста — механизм отката, не подписки.

## Единый словарь инструментов (каким его видит агент)

| Тул | Параметры | Возврат | Примечания |
|---|---|---|---|
| `daw.get_session` | — | `{host, tempo, meter, tracks[], markers[], length_samples, path}` | всегда перед действием |
| `daw.set_tempo` | `{bpm}` | `{bpm, tick}` | 20..300 |
| `daw.adopt_loop` | `{bpm, key, source}` | `{tempo, marker}` | `set_tempo` + key-маркер; API тональности нет ни у одного хоста — convention-маркер |
| `daw.import_midi` | `{path, track?, at?}` | `{tracks: [...]}` | path — внутри workspace |
| `daw.add_marker` | `{name, at?}` | `{id, number}` | key/структурные пометки |
| `daw.render` | `{path, normalize?}` | `{path, seconds, lufs, peak_db}` | хост-зависимо, см. матрицу |

Инструменты, которых контракт **намеренно не содержит**: редактирование нот
(ноты производит midi-gen в файл, хост импортирует), микширование
(громкости/панорамы — работа человека в DAW), плагины.

## Реализации

| Адаптер | Статус | Где |
|---|---|---|
| soundcraft | ✅ реализован | ZCode-плагин soundcraft (native MCP) |
| ardour | 🔨 спайк | `src/mcp_servers/daw_ardour/` (python-osc) — после спайка |
| reaper | 📦 внешний | dawmcp подключается в конфиг как есть |
| ableton | ⏸ shelved | Live не запускается нативно на Linux (решение 2026-11-22) |

## Не-цели контракта

- Единый рендер-формат поверх хостов: каждый хост рендерит по-своему,Self-Check
  анализирует файл — формат нас не волнует.
- Редактирование нот/миксов через контракт: партитура живёт в MIDI-файлах
  midi-gen, финальные штрихи — человек в DAW.
- Претензия на «универсальный DAW-язык»: словарь минимален, расширяется
  только когда второй хост реально блокируется без фичи.
